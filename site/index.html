Systems programming,
down to the bedrock.

Bedrock is an imperative, statically typed systems programming language built around simplicity, readability, and practicality — the control of a systems language without the ceremony.

Memory is managed automatically through a region-based memory model. No new, no free, no garbage collector. Explicit low-level control stays available when you need it, behind unsafe.

Read the docs View the grammar

Familiar by design

An imperative core: procedures, functions, structs, and modules. No classes, no inheritance, no hidden control flow.

Regions, not GC

Scoped arenas are bulk-freed the instant their block exits. Lifetimes are checked at compile time by a simple escape rule.

Explicit failure

Errors and optional values live in the type system — File! can fail, ?User may be absent. Nothing fails silently.

A taste of Bedrock

import io

type Person = struct
    name: str,
    age: u32,
end

proc greet(p: Person)
    io.print("Hello ")
    io.println(p.name)
end

proc main()
    var user = Person(
        name = "Alice",
        age = 24,
    )

    greet(user)
end

Every block begins with a keyword and ends with end. What you see is what runs.
